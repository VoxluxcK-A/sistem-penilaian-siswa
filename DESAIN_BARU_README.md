## 🎨 **Design System**

### **Colors:**
- **Primary**: #ff9a00 (Orange)
- **Secondary**: #ffd700 (Gold)
- **Success**: #28a745 (Green)
- **Danger**: #dc3545 (Red)
- **Dark**: #333 (Text)
- **Light**: #666 (Secondary text)

### **Typography:**
- **Font Family**: Poppins (Google Fonts)
- **Weights**: 300, 400, 500, 600, 700
- **Hierarchy**: Clear heading and body text distinction

### **Components:**
- **Cards**: Rounded corners (15-20px), subtle shadows
- **Buttons**: Gradient backgrounds, hover animations
- **Forms**: Modern input styling with focus states
- **Alerts**: Color-coded with icons and proper spacing

### **Effects:**
- **Glass Morphism**: `backdrop-filter: blur(10px)`
- **Gradients**: Linear gradients for backgrounds and buttons
- **Shadows**: Layered shadows for depth
- **Animations**: Smooth transitions and hover effects

## 📱 **Responsive Design**

### **Breakpoints:**
- **Mobile**: < 768px
- **Tablet**: 768px - 1024px
- **Desktop**: > 1024px

### **Mobile Optimizations:**
- Stacked layout untuk mobile
- Touch-friendly button sizes
- Optimized typography scaling
- Simplified navigation
